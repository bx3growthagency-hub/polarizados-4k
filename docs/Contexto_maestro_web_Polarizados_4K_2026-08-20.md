## 1. REGLAS PARA USAR ESTE DOCUMENTO

La web debe distinguir entre cuatro tipos de información:

- **Confirmado y repetido:** dato mencionado de forma consistente en varias conversaciones o documentos.
- **Registrado, pero requiere validación antes de publicarse:** dato usado en campañas o propuestas que puede haber cambiado o necesita soporte oficial.
- **Propuesta de trabajo:** función, texto o idea planteada, pero no necesariamente aprobada o implementada.
- **No disponible:** información que no existe en la memoria y que no se debe inventar.

La IA, diseñador o desarrollador que use este documento debe cumplir estas reglas:

1. No inventar años de experiencia, fecha de fundación, número de instalaciones, cantidad de clientes, cifras de ventas, premios, certificaciones, alianzas, porcentajes técnicos, testimonios ni garantías.
2. No publicar precios como vigentes sin confirmación final de Polarizados 4K.
3. No presentar una promoción antigua como si continuara activa.
4. No afirmar que una integración digital ya está instalada si solo fue propuesta para la nueva web.
5. No mezclar información de BX3, CarLux, CBT Peruvian, Sky300 Performance u otros negocios con Polarizados 4K.
6. Mantener siempre el nombre correcto: **Polarizados 4K**.
7. Si existe un conflicto entre datos, usar un marcador pendiente de validación en lugar de escoger uno arbitrariamente.
